# Social_Anxiety_ML_Project

## 📘 Lektionssyfte  
Att förstå grunderna i **linjär regression** genom att analysera samband mellan social ångest och faktorer som **ålder** eller **användning av sociala medier**.

## 🎯 Lärandemål  
Eleverna ska kunna:

- **Träna på dataanalys och visualisering** genom att utforska datasetet.  
- **Bygga en enkel linjär regressionsmodell** för att undersöka samband mellan variabler.  
- **Reflektera över etiska implikationer** av AI‑modeller, särskilt när de används inom psykologi och känsliga områden.
- 


Dataset
Datasetet hämtas automatiskt via kagglehub:
import kagglehub
path = kagglehub.dataset_download("natezhang123/social-anxiety-dataset")



Tekniker och bibliotek
Projektet använder:
- Python
- NumPy, Pandas
- Matplotlib, Seaborn
- Scikit‑learn
- XGBoost (valfritt för mer avancerade modeller)
- KaggleHub för dataset‑hämtning
- 


Modellering
Projektet inkluderar:
- Train/test‑split
- Linjär regression
- Utvärdering med:
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- R²‑score
- Visualisering av regressionslinje och residualer



Etiska reflektioner
Projektet lyfter frågor kring:
- Risker med att använda AI‑modeller på känsliga psykologiska data
- Bias och felaktiga slutsatser
- Integritet och dataskydd
- Ansvarsfull användning av prediktiva modeller inom psykologi
